Tool: Find Reference Chain

The Find Reference Chain tool searches atomic structure databases (experimental, computational, or both) for suitable reference models for query chains in ChimeraX. It runs the Phenix program find_reference (under development). The command implementation is phenix findReference. Users should cite:

See also the video: Phenix/ChimeraX setup

Phenix must be installed locally and the PhenixUI bundle installed in ChimeraX. The program location can be specified (saved in preferences) beforehand with the phenix location command. If no location has been specified, however, ChimeraX will look for a folder name that starts with phenix in the user's home directory, and on Mac only, if none is found there, then in the system /Applications folder.

Find Reference Chain can be started from the Phenix section of the Tools menu.

The structure chains of interest should be already open and chosen from the menu in the dialog. The user may choose to search databases of computational (modeled) structures only, experimental structures only, or both (initial default).

Keep Phenix input/output files indicates whether to save the associated input and output files. If this option is checked (initial default), clicking Apply (or OK, which also dismisses the dialog) will raise a file browser window for the user to specify a folder in which to save these files, and specifying the folder will start the search. If this option is not checked, clicking Apply or OK will start the search immediately.

Clicking Close simply dismisses the dialog without running the search, whereas Help shows this page in the Help Viewer.

Running the search also saves the current settings of the tool as user defaults. The results are shown as a table in the Log.
