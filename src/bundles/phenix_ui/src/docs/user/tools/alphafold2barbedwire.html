Tool: AlphaFold2 Barbed Wire

The AlphaFold2 Barbed Wire tool in ChimeraX runs the Phenix program barbed_wire_analysis (under development, part of the MolProbity evaluation suite) on the specified atomic model(s). The command implementation is phenix barbedWire. The analysis was developed for AlphaFold2 models and applies to protein chains with pLDDT values read from the B-factor field of their input files. Users should cite:

Categorizing prediction modes within low-pLDDT regions of AlphaFold2 structures: near-predictive, pseudostructure and barbed wire. Williams CJ, Chen VB, Richardson DC, Richardson JS. Acta Crystallogr D Struct Biol. 2025 Oct 1;81(Pt 10):558-572.

See also the video: Phenix/ChimeraX setup

Phenix must be installed locally and the PhenixUI bundle installed in ChimeraX. The program location can be specified (saved in preferences) beforehand with the phenix location command. If no location has been specified, however, ChimeraX will look for a folder name that starts with phenix in the user's home directory, and on Mac only, if none is found there, then in the system /Applications folder.

AlphaFold2 Barbed Wire can be started from the Phenix section of the Tools menu.

The AlphaFold2 model to Analyze should be already open and chosen from the menu of atomic structures in the dialog. Options:

  • Uncategorized structure color (default
    ) – color to use for uncategorized residues
    • Show category-to-color key (default on) – whether to display a color key in the graphics window explaining the categories assigned by barbed wire analysis

Clicking OK categorizes and colors the amino acid residues as follows:

  • Predictive
    – high pLDDT, high packing
  • Unpacked high pLDDT
  • Near-predictive
    – low pLDDT, high packing, low outliers
  • Pseudostructure
    – low pLDDT, low packing, low outliers
  • Barbed wire
    – low pLDDT, low packing, high and/or barbed-wire-characteristic outliers
  • Unphysical
    – low pLDDT, high packing, high and/or barbed-wire-characteristic outliers (rare)
  • Uncategorized – the color specified for uncategorized residues in the input dialog (above; default
    )

The residues are assigned an attribute named barbed_wire_category with values equal to the category names listed above (character strings with the same capitalization and embedded spaces as shown above, e.g., “Barbed wire”).

Clicking Close simply dismisses the dialog without running the analysis, whereas Help shows this page in the Help Viewer.
