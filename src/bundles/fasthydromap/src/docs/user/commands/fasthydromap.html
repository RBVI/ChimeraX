Command: fasthydromap

The fasthydromap command predicts per-residue hydrophobicity or water-structure values with FastHydroMap, stores the values as ChimeraX residue attributes, and optionally colors the structure.

Installation

Before the first prediction, install FastHydroMap and PyTorch into an isolated, bundle-managed Python environment:

fasthydromap install [ directory ] [ torchVariant  variant ] [ wait  true | false ]

The default installation directory is inside the ChimeraX user data directory, and the default Torch variant is cpu. A CUDA-enabled variant supported by FastHydroMap, such as cu121, can be requested with torchVariant. The installation may take several minutes and requires internet access.

Usage

fasthydromap structures [ quantity  fdewet | pc1 | pc2 | pc3 ] [ color  true | false ] [ target  letters ] [ showAtoms  true | false ] [ palette  palette ] [ range  low,high ] [ installLocation  directory ]

If no model is specified, all open atomic structures are processed. The quantity defaults to fdewet. The resulting residue attributes are named fasthydromap_fdewet, fasthydromap_pc1, fasthydromap_pc2, and fasthydromap_pc3.

The target letters select atoms (a), cartoons (c), and surfaces (s); the default is acs. Each quantity has a scientifically chosen default palette and numeric range, which can be overridden with palette and range.

Examples

fasthydromap #1
Predict Fdewet for model #1 and color its atoms, cartoon, and surface.
fasthydromap #1 quantity pc1 target cs
Predict PC1 and color only the cartoon and surface.
fasthydromap #1 quantity pc2 palette blue:white:red range -2,8
Predict PC2 using a custom color palette and range.
