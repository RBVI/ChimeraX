Command: fasthydromap

The fasthydromap command predicts per-residue hydrophobicity or water-structure values with FastHydroMap, stores the values as ChimeraX residue attributes, and optionally colors the structure. Only amino-acid polymer residues are sent to FastHydroMap. Nucleic acids, waters, ions, and ligands remain in the open model but are excluded from the temporary prediction input. A warning in the Log lists examples of ignored residues.

FastHydroMap assumes neutral histidine chemistry. It does not distinguish HID/HIE (or HSD/HSE) tautomer assignments and does not represent the positive charge of HIP/HSP. A warning is shown for structures containing histidine.

Unlike sequence hydropathy scales that assign one value to each amino-acid identity, Fdewet is a context-dependent thermodynamic measure of how readily water can be removed from a local surface. Lower Fdewet is more hydrophobic; higher Fdewet is more hydrophilic. See the HydroMap and FastHydroMap paper for the method and applications.

Installation

Before the first prediction, install FastHydroMap and PyTorch into an isolated, bundle-managed Python environment:

fasthydromap install [ directory ] [ torchVariant  variant ] [ wait  true | false ]

The default installation directory is inside the ChimeraX user data directory, and the default Torch variant is cpu. A CUDA-enabled variant supported by FastHydroMap, such as cu121, can be requested with torchVariant. The installation may take several minutes and requires internet access. When it finishes, the Log shows clickable commands for a first prediction and this help page.

Usage

fasthydromap structures [ quantity  fdewet | pc1 | pc2 | pc3 ] [ color  true | false ] [ target  letters ] [ showAtoms  true | false ] [ palette  palette ] [ range  low,high ] [ installLocation  directory ]

If no model is specified, all open atomic structures are processed. The quantity defaults to fdewet. The resulting residue attributes are named fasthydromap_fdewet, fasthydromap_pc1, fasthydromap_pc2, and fasthydromap_pc3.

Each quantity has a scientifically chosen default palette and numeric range. These defaults are intended for normal use. The palette and range options customize the color scale, while target and showAtoms provide additional display-only control.

Interpretation

MapNegative or low valuesPositive or high values
FdewetEasier to remove water; more hydrophobic Water retained more strongly; more hydrophilic
PC1More tetrahedral water ordering; generally more hydrophobic Shift toward simple-fluid/icosahedral motifs
PC2Enrichment around 125–150° and depletion around 80–105° Enrichment around 80–105° (maximum loading at 92.5°) and depletion around 120–150°; disordered water associated with large, smooth hydrophobic interfaces
PC3Depleted high-coordination water signature More highly coordinated water near polar/charged sites; generally more hydrophilic

PC1-PC3 are signed water-structure descriptors, not energy scales. PC2 is particularly sensitive to surface geometry. Its positive, roughly 90°-centered signature can be called disordered, simple-fluid-like, or vapor-interface-like, but it is not a literal ideal-gas order parameter. It should be interpreted alongside Fdewet and the structure.

Examples

fasthydromap #1
Predict Fdewet for model #1 and color its atoms, cartoon, and surface.
fasthydromap #1 quantity pc1
Predict PC1 and color the structure with its default palette and range.
fasthydromap #1 quantity pc2 palette blue:white:red range -2,8
Predict PC2 using a custom color palette and range.
