Tool: File History

The File History lists previously opened files as images and names that can be clicked to reopen the data. This interface can be started as a separate tool from the Tools menu (more...) and/or shown in the main window as part of Rapid Access . See also: ChimeraX window, open

The File History shows thumbnail images and the filenames or identifiers of previously opened data. Clicking an image or name reopens the data, if it still exists, using the same options as used previously. Simply pausing the cursor over an image or filename without clicking shows the data's full pathname or database information.

Thumbnails can be grouped into named sections, for example one per project. Once any section has been defined, each section is shown with its name as a heading, and files that are not in any section are shown first under Recent, most recently used first. Files in a section stay in the position where they were placed even when they are reopened. A thumbnail can be dragged with the mouse into a section and dropped at a specific position, or dragged onto Recent to remove it from its section. Several thumbnails can be selected by Ctrl-clicking (⌘-clicking on Mac) to add or remove individual thumbnails, or Shift-clicking to select a range; dragging any selected thumbnail moves all of them, keeping their order. Clicking the background clears the selection.

The sections are saved in a separate file from the history itself so that they are preserved if an older version of ChimeraX (which does not know about sections) is used.

The tool's context menu includes:

  • Open – open the file under the mouse (same as clicking it), or all selected files
  • Move to section – move the file under the mouse, or all selected files, into a section, Recent, or a New section... to be named
  • Remove from history – remove the file under the mouse, or all selected files, from the history (the file itself is not deleted)
  • Add new files to this section – newly opened or saved files are placed in the section under the mouse instead of Recent; the heading of that section notes (new files added here)
  • Rename section..., Move section up, Move section down – organize the section under the mouse
  • Remove section – remove the section under the mouse; its files move back to Recent
  • New section... – define a new, initially empty section
  • Show full file names – whether to the show the entire name of each file instead of shortening the long names with ellipses (...); saved as a preference
  • Remove deleted files – remove references to files that no longer exist
  • Clear file history – remove all files (any sections are kept, but emptied)

The history is stored in a file in a platform-dependent standard location and carries over between different ChimeraX sessions. The location can be reported with command:

info path user unversioned data

Images are saved right after data files are opened. Each image shows the corresponding data in the absence of other models.
